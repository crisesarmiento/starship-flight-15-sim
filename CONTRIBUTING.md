# Contributing

Thanks for wanting to help!

- **Data needs sources.** Every vehicle or mission value in `data/` must include a public source URL. Mark estimates as estimates.
- **Small PRs.** One topic per pull request, with a short description and a screenshot or GIF for visual changes.
- **No secrets or paid APIs.** The sim must run fully offline after `npm install`.
- Be kind. See the [Code of Conduct](CODE_OF_CONDUCT.md).
